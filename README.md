# detalkipro-chain

Блокчейн‑сеть экосистемы DetalkiPro.

## Статус
В активной разработке.

## Стек
- Java 17 / Maven или Go (выбери нужное)
- Docker

## Как вносить правки
1. git checkout -b feature/blockchain-<тема>
2. Вноси изменения
3. git commit -m "..."
4. Создай PR в main
