# DetalkiPro Chain — блокчейн-инфраструктура для маркетплейса и сети ПВЗ

**DetalkiPro Chain** — рабочая блокчейн-сеть для маркетплейса «ДеталькиПро.ру» и сети пунктов выдачи заказов (ПВЗ). Проект объединяет e-commerce, сервис по ремонту техники и сообщество радиолюбителей в единую экосистему с гибридным консенсусом Proof-of-Commerce.

Автор: Падерин Павел Владимирович  
Язык: Go 1.24  
Статус: Рабочая версия v0.1.0 (L1 + L2 слои)

## 🎯 Суть решения: Proof-of-Commerce в реальных бизнес-процессах

DetalkiPro Chain реализует консенсус Proof-of-Commerce: сложность блока динамически снижается при наличии подтверждённых коммерческих транзакций — заказов на «ДеталькиПро», оплат ремонта телевизоров, выкупа запчастей. Это делает сеть экономически полезной с первого дня.

## 🏗 Архитектура под твой бизнес

- **ПВЗ как узлы сети**: каждая точка (включая ПВЗ на Лиговском проспекте) работает как оракул и/или майнер, подтверждая статусы заказов и ремонтов.
- **Радиолюбительский слой (L2)**: отдельный слой для энтузиастов с упрощённым майнингом и бонусами за участие в инфраструктуре.
- **Интеграция с ремонтом техники**: транзакции фиксируют этапы ремонта телевизоров (матрицы, T‑Con, подсветка), запчастей и сервисных работ — это важно для гарантий и отчётности.
